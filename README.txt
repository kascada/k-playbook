k-playbook
==========

Enthält Claude Code Skills/Commands (.md-Dateien) die projektübergreifend genutzt werden.

Setup
-----
Das Verzeichnis liegt in ~/dev/k-playbook/ und ist per Symlink eingebunden:

    ~/.claude/commands -> ~/dev/k-playbook/commands

Versionierung
-------------
Git-Repo mit Remote auf GitHub:

    git@github.com:kascada/k-playbook.git

Nach Änderungen:

    cd ~/dev/k-playbook
    git add .
    git commit -m "..."
    git push
