Skills-Verzeichnis
==================

Enthält Claude Code Skills (.md-Dateien) die projektübergreifend genutzt werden.

Setup
-----
Das Verzeichnis liegt in ~/dev/Skills/ und ist per Symlink eingebunden:

    ~/.claude/Skills -> ~/dev/Skills/

Versionierung
-------------
Git-Repo mit Remote auf GitHub:

    git@github.com:kascada/skills.git

Nach Änderungen:

    cd ~/dev/Skills
    git add .
    git commit -m "..."
    git push
